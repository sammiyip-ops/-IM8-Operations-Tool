Courier Splitter — daily order assignment
📋 Daily Courier Split — SOP
① Export from D365
Go to D365 → Order lines → Filter by today's date → Export to Excel. Save as the raw Order lines file.

② Upload to this tab
Click the upload zone below and select the exported file. The tool reads: Shopify reference, Item number, Country/region, Quantity, Status.

③ Review courier rules
Check the rule table. Adjust DHL conditions per country if today's split differs from default (e.g. include SGP single-item orders in DHL).
④ Generate & download
Click Generate courier Excel. Review the stats and country breakdown. Download the Excel file.

⑤ Output file (8 sheets)

FEDEX NO TW Excl. Taiwan + count pivot

⑥ DHL conditions explained
Single SKU — 1 unique product in the order
Total qty = 1 — total units ordered = 1
Not a duplicate order — Shopify ref appears only once in file (= single line)
Not quarterly subscription — no FG-000236 to FG-000243
All ticked conditions must be met (AND logic)
Upload the raw Order lines export from D365. The tool assigns each order to a courier and generates the pivot Excel file (8 sheets) for printing.
